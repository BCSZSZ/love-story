# 02｜页面、交互与视觉设计

版本：2.0.0 · 日期：2026-09-28。

## 1. 信息架构与标题

采用客户端 SPA 和 hash 路由：`/#/`、`/#/form`、`/#/result`、`/#/privacy`、`/#/admin`。URL 不包含答案、匿名记录管理 token 或结果明细；普通页面不突出后台入口。

首页标题使用 `{titleLabel}·爱情故事`。匹配城市是显式单选，默认东京，种子选项只有东京、上海、北京、大阪等真实城市；一个选择同时代表双方现居城市。用户切换城市后保留其他答案并立即重算。旧 v1 草稿迁移时必须确认城市，确认前不能完成或上传为 v2。

首页展示 80 亿演示起点、非真实统计说明、保存一年提示和“开始估算”。填写页由运行时配置生成问题卡；v2 种子为 62 问题，管理员以后新增 active 问题时无需重新写页面。

## 2. 填写页

PC 宽度达到 1024px 时使用主区域加右侧 sticky 摘要；手机和平板优先单列。问题卡依次显示“我的情况”和“对方要求”；对象要求仍用按钮、多选、预设端点和相对条件，避免长文本和任意脚本输入。

右侧/手机 sticky 摘要至少包含当前同城条件池、已启用要求数、两侧分数、保存状态和“查看完整结果”。所有数字注明“演示模型”。成年人基础步骤不可取消。

触控目标约 44×44 CSS px，数值输入至少 16px 字号，页面不得横向溢出。按钮比例条按 0～100% 线性显示；“普通/较少/稀少/极少”只用于说明，不改变计算。

## 3. 结果页：两个结果

结果首屏并列或纵向展示：

- **同城条件池**：所选城市成年人中，经过当前条件强度后的估算规模。
- **圈层内可达**：在当前有效可触达规模中，按同一条件覆盖率得到的估算规模。

两者必须同时显示所选城市、演示参数提示和阶段性 issue。`0 < N < 1` 显示“预计不足 1 人”；数学零才显示“本模型下为 0”。不能用低结果羞辱用户。

## 4. 可触达圈层

结果页提供单选圈层和多个助力 toggle。种子值如下：

| 名称 | 基础规模 |
|---|---:|
| 日常圈 | 2,000 |
| 拓展圈 | 5,000 |
| 城市圈 | 10,000 |

| 助力 | 增幅 |
|---|---:|
| 朋友助力 | +50% |
| 家庭助力 | +25% |
| 相亲服务助力 | +100% |

选择立即形成“尚未应用”的预览；只有点击“应用到本次结果”才修改正式草稿和触发保存。放弃预览恢复已应用状态。增幅按基础圈层加法叠加，界面说明不同来源可能重叠，数字不是实际好友数或平台用户数。

## 5. 五档排除强度

每个已经设置具体条件的问题展示五档：

| 文案 | 系数 |
|---|---:|
| 必须满足 | 1.0 |
| 尽量满足 | 0.8 |
| 可以商量 | 0.6 |
| 宽松考虑 | 0.4 |
| 无要求 | 0 |

档位只调排除强度，不改变原来选择的年龄区间、金额门槛或类别集合。每一行人数只预览“以已应用草稿为基线、仅把该行切到当前预览档”的结果；页面另设“多项合并预览”显示所有未应用修改的合并效果。

“影响最大的三项”从当前合并预览出发，各自只向相邻下一档移动一次，按同城条件池增量排序。点击建议只加入预览；预览不保存、不新建记录，也不把多个建议的增量相加。

0.4～1.0 的条件仍使用原具体要求计算要求分；0 才把该项从要求分移除。页面必须明确此语义，避免把“排除强度”和具体年龄/金额档位混为一谈。

## 6. 分享卡与异常

`ShareCard` 使用独立 DOM，默认包含动态标题、所选城市、两个结果、圈层/助力摘要、两侧评分、已应用要求摘要、配置版本/checksum 和“演示参数／非真实人口统计”。自身详细答案默认不导出；隐藏条件只影响图片，并标注“部分条件已隐藏”。

导出目标宽 1080px、内容自适应高度；像素过大时降低 pixel ratio。移动浏览器不能直接下载时显示完整 PNG 供长按保存。图片不上传云端。

保存状态必须区分本机已保存、待上传、上传中、云端已保存、上传失败、记录到期和凭据失效。断网或配置服务故障不能阻止使用已固定/内置配置本机计算，但不得伪称云端保存或发布成功。

## 7. 管理后台

`/#/admin` 获取公开的管理员认证配置。生产环境使用 Cognito 托管登录 Authorization Code + PKCE；本机开发在服务端明确返回 `enabled: false` 时使用本地管理员模式。后台有五个页签：

1. 配置概览与版本列表。
2. 条件管理：搜索、编辑、新增问题；未发布问题可删除，发布问题只能停用。
3. 选项、比例与评分。
4. 城市、圈层、助力和五档强度。
5. Excel 导入/导出、验证、保存草稿、发布与激活历史版。

每次修改显示未发布状态；验证、保存、发布、激活分别报告服务端结果。导入先在浏览器安全解析和共享校验，失败显示定位信息；通过后只替换本地编辑副本，不自动发布。

## 8. 视觉与可访问性

视觉采用清爽数据工具风格：米白背景、白色卡片、深墨正文、青绿主操作、陶橙稀缺强调。字体使用系统中文/日文字体，不加载第三方字体 CDN。尊重 `prefers-reduced-motion`；颜色之外同时使用文字和数值表达状态。
